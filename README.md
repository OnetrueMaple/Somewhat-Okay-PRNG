# Somewhat Acceptable PRNG

### What is this project?
It's a program that tries to produce random numbers with real entropy, no matter the source, no matter the OS.
If I can do so statelessly that would be cool too.

### How to use

Right now, just download the files and run the 'rng.py' document.
You'll have to edit the 'nums' parameter near the bottom of the file yourself, and its all in bitstream form for now.
It's like that for testing purposes, most of what you see now is subject to change as I work on this more.
